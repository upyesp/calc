# epher 用户指南

欢迎！epher 是一款可编程、可脚本化的计算器。你可以用它做快速计算，也可以构建自己的函数和小程序——并且所有功能都支持八种语言。

本指南面向完全初学者。它从最简单的计算开始，逐步深入到语言的完整功能。每个示例都显示你输入的内容以及 epher 的回应。

epher 有四种使用方式——选择最适合你的那一种：

| 版本 | 是什么 | 何时选用 |
|---|---|---|
| **网页应用**（PWA） | 在浏览器中运行，可安装，可离线使用 | 想最快开始；无需安装 |
| **桌面应用** | 带独立窗口的常规桌面程序 | 想要一个常规应用程序 |
| **命令行**（CLI） | 终端中的文本命令；也有交互式会话 | 常驻终端、喜欢脚本 |
| **终端界面**（TUI） | 终端内的全屏程序 | 想要带图表和屏幕历史的终端应用 |

桌面应用、命令行和终端界面是同一个程序：一次下载安装的 `epher` 命令能完成这三件事。网页应用是例外——完全无需下载。

四个版本理解完全相同的语言。学会一次，随处可用。

## 1. epher 语言

本章讲解所有 epher 版本共享的语言。在网页应用或桌面应用中，输入表达式并按**回车**（或点击 **=** 按钮）。在 CLI 中，用 `epher repl` 启动会话，然后在 `epher>` 提示符后输入。在 TUI 中（`epher tui`），直接输入并按**回车**。在 CLI 中你也可以输入 `epher "表达式"` 直接计算一个表达式。

### 1.1 你的第一个计算

输入：

```epher
2 + 3 * 4
```

epher 回答：

```text
14
```

乘法和数学中一样先于加法计算。这个规则称为*运算符优先级*。

### 1.2 运算顺序

完整的优先级顺序，从强到弱：

1. `!` 阶乘
2. `^` 乘方
3. `*` 和 `/` 乘法和除法
4. `+` 和 `-` 加法和减法

用括号改变顺序：

```epher
(2 + 3) * 4
```

```text
20
```

`^` 运算符计算乘方，并且从右向左结合：

```epher
2 ^ 10
```

```text
1024
```

```epher
2 ^ 3 ^ 2
```

```text
512
```

（`2 ^ 3 ^ 2` 表示 `2 ^ (3 ^ 2)`，即 `2 ^ 9` = 512。）

乘方可以是分数——`2 ^ 0.5` 就是 2 的平方根：

```epher
2 ^ 0.5
```

```text
1.4142135623730951
```

减法和除法从左向右计算：

```epher
10 - 3 - 2
```

```text
5
```

### 1.3 特殊数字 pi、e、tau 和 phi

著名的常数都已经内置：

```epher
pi
```

```text
3.141592653589793
```

```epher
2 * pi
```

```text
6.283185307179586
```

```epher
e
```

```text
2.718281828459045
```

还有两个：`tau` 是一整圈（2 pi），`phi` 是黄金比例：

```epher
tau
```

```text
6.283185307179586
```

```epher
phi
```

```text
1.618033988749895
```

### 1.4 比较与逻辑

你可以比较数字。结果是 `true`（真）或 `false`（假）：

| 比较 | 含义 |
|---|---|
| `a > b` | a 大于 b |
| `a < b` | a 小于 b |
| `a >= b` | a 大于或等于 b |
| `a <= b` | a 小于或等于 b |
| `a == b` | a 等于 b（注意是两个 `=`） |
| `a != b` | a 不等于 b |

```epher
3 > 2
```

```text
true
```

```epher
1 != 2
```

```text
true
```

用 `and`、`or` 和 `not` 组合比较：

```epher
3 > 2 and 2 < 3
```

```text
true
```

```epher
not 3 > 2
```

```text
false
```

### 1.5 变量

用一个 `=` 给值命名：

```epher
x = 5
```

```text
5
```

epher 会把值重复给你。从现在起，`x` 可以随处使用：

```epher
x ^ 2
```

```text
25
```

你可以随时更改变量——它一直保持自己的值，直到你更改它：

```epher
x = x + 1
```

```text
6
```

> 名称可以包含字母和下划线，如 `radius` 或 `my_total`。不能包含空格，也不能以数字开头。

### 1.6 常量：永不改变的名称

*常量*是一个值永不改变的名称——就像内置的 `pi`，但由你自己选择。用 `const`
定义：

```epher
const tax = 0.2
```

```text
0.2
```

在任何可以使用数字的地方都可以使用它：

```epher
100 * (1 + tax)
```

```text
120
```

这个值是固定的：用 `=` 修改它会报错，

```epher
tax = 0.25
```

```text
error: cannot assign to constant tax
```

两次定义同一个常量同样会报错：

```epher
const tax = 0.25
```

```text
error: constant already defined: tax
```

常量与变量还有一个不同之处：和 `pi` 一样，它可以在你自己的函数里使用。

```epher
const g = 9.81
```

```text
9.81
```

```epher
def weight(m) = m * g
```

```epher
weight(80)
```

```text
784.8000000000001
```

像保存函数一样，用 `save tax` 把常量保存到以后的会话（第 4.4 章）。

> 变量和常量不能共用一个名称：`const tax = 0.2` 之后，`tax = ...` 永远是
> 错误。换一个新名称，或开始一个新的会话。

### 1.7 用 if 做判断

`if` 在两个值之间选择：

```epher
if 3 > 2 then 10 else 20
```

```text
10
```

形式永远是 `if 条件 then 为真时的值 else 为假时的值`。`else` 部分必不可少。

带变量的更有用示例：

```epher
price = 100
if price > 50 then 2 else 1
```

```text
2
```

> epher 没有文本值——`if` 的两个分支必须是数字（或比较的结果）。

### 1.8 用 while 循环

只要条件成立，`while` 就重复执行一条语句：

```epher
x = 0; while x < 5 do x = x + 1; x
```

```text
5
```

把这个脚本读作：*x 从 0 开始；当 x 小于 5 时，给 x 加 1；然后显示 x。*结果是 5，因为循环执行了五次。

> **安全网：** epher 会在 100 000 步之后停止任何循环并显示 `error: step limit exceeded`。这能保护你免受永不结束的循环的困扰。如果看到这个错误，说明你的条件可能永远不会变成假。

### 1.9 用 def 定义自己的函数

函数是带有名称和参数的计算：

```epher
def f(x) = x ^ 2
```

然后使用它：

```epher
f(7)
```

```text
49
```

函数可以有多个参数：

```epher
def area(w, h) = w * h
area(3, 4)
```

```text
12
```

也可以定义没有参数的函数：

```epher
def answer() = 42
answer()
```

```text
42
```

### 1.10 递归：调用自身的函数

最著名的例子——斐波那契数列：

```epher
def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
```

```epher
fib(10)
```

```text
55
```

`fib(10)` 是第 10 个斐波那契数。函数用更小的参数调用自己，直到达到 `n <= 1`。这能成立是因为 `if ... then ... else ...` 形式只计算它需要的分支。

> 函数体是一个单独的表达式——一行。需要组合多个计算时，改用 `;` 写成脚本（见下一节）。

### 1.11 脚本：一次执行多条语句

*脚本*是用 `;` 连接、依次执行的若干语句：

```epher
x = 10; y = x + 5; x + y
```

```text
25
```

脚本是构建小程序的方式：设置变量、循环、显示最终结果。

### 1.12 精确结果：frac、dec 和 big

通常 epher 像袖珍计算器一样用小数计算。有些数字用精确形式更好看。

**frac(n, d)** 生成精确分数：

```epher
1 / 3
```

```text
0.3333333333333333
```

```epher
frac(1, 3)
```

```text
1/3
```

分数在计算过程中保持精确：

```epher
frac(1, 3) * 3
```

```text
1
```

**dec(x)** 生成精确小数。比较这两个：

```epher
0.1 + 0.2
```

```text
0.30000000000000004
```

```epher
dec(0.1) + dec(0.2)
```

```text
0.3
```

第一个结果是每台计算机处理小数时都会产生的微小舍入误差。`dec()` 会消除它。

**big(x)** 生成精确整数，用于超出袖珍计算器范围的数值：

```epher
big(10 ^ 20)
```

```text
100000000000000000000
```

### 1.13 内置函数

epher 拥有科学计算器的全部函数，按家族分组。

三角函数使用弧度——用 `deg` 和 `rad` 转换：

| 函数 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `sin(x)`、`cos(x)`、`tan(x)` | 三角函数 | `sin(pi / 2)` | `1` |
| `asin(x)`、`acos(x)`、`atan(x)` | 反三角函数 | `atan(1)` | `0.7853981633974483` |
| `atan2(y, x)` | 点 (x, y) 的角度 | `atan2(1, 1)` | `0.7853981633974483` |
| `deg(x)` | 弧度 → 角度 | `deg(pi)` | `180` |
| `rad(x)` | 角度 → 弧度 | `rad(180)` | `3.141592653589793` |
| `sinh(x)`、`cosh(x)`、`tanh(x)` | 双曲函数 | `sinh(1)` | `1.1752011936438014` |
| `asinh(x)`、`acosh(x)`、`atanh(x)` | 反双曲函数 | `acosh(1)` | `0` |

幂、根和对数（计算器上的 `log` 是以 10 为底）：

| 函数 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `sqrt(x)` | 平方根 | `sqrt(16)` | `4` |
| `cbrt(x)` | 立方根 | `cbrt(-27)` | `-3` |
| `root(n, x)` | n 次方根 | `root(3, 8)` | `2` |
| `exp(x)` | e 的 x 次方 | `exp(1)` | `2.718281828459045` |
| `ln(x)` | 自然对数 | `ln(e)` | `1` |
| `log(x)` | 以 10 为底的对数 | `log(100)` | `2` |
| `log2(x)` | 以 2 为底的对数 | `log2(8)` | `3` |
| `logb(b, x)` | 以 b 为底的对数 | `logb(2, 8)` | `3` |
| `hypot(a, b)` | 斜边 | `hypot(3, 4)` | `5` |
| `5!`（也可写作 `fact(n)`） | 阶乘 | `5!` | `120` |

舍入、符号和整数：

| 函数 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `abs(x)` | 绝对值 | `abs(-3)` | `3` |
| `floor(x)` / `ceil(x)` | 向下 / 向上取整 | `floor(2.7)` | `2` |
| `round(x)` | 四舍五入，.5 远离零 | `round(2.5)` | `3` |
| `trunc(x)` | 去掉小数部分 | `trunc(-2.9)` | `-2` |
| `sign(x)` | -1、0 或 1 | `sign(-5)` | `-1` |
| `ncr(n, r)` | 组合数 | `ncr(52, 5)` | `2598960` |
| `npr(n, r)` | 排列数 | `npr(5, 2)` | `20` |
| `gcd(a, b)` / `lcm(a, b)` | 公约数和公倍数 | `gcd(12, 18)` | `6` |
| `mod(a, b)` | 余数 | `mod(7, 3)` | `1` |

统计函数接受任意数量的参数：

| 函数 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `sum(...)` / `product(...)` | 总和 / 总积 | `sum(1, 2, 3)` | `6` |
| `mean(...)` | 平均数 | `mean(1, 2, 3)` | `2` |
| `median(...)` | 中位数 | `median(1, 2, 3, 4)` | `2.5` |
| `min(...)` / `max(...)` | 最小值 / 最大值 | `max(4, 1, 3)` | `4` |
| `variance(...)` / `stdev(...)` | 离散程度 | `stdev(2, 4)` | `1` |

第 1.12 节的精确层保持不变：

| 函数 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `frac(n, d)` | 精确分数 | `frac(1, 3)` | `1/3` |
| `dec(x)` | 精确小数 | `dec(0.1)` | `0.1` |
| `big(x)` | 精确整数 | `big(10 ^ 20)` | `100000000000000000000` |

它们可以像其他一切一样组合：

```epher
min(sqrt(16), 5)
```

```text
4
```

### 1.14 读懂错误

出问题时，epher 会告诉你，而不是猜测：

```epher
1 / 0
```

```text
error: division by zero
```

```epher
sqrt(-4)
```

```text
error: domain error: sqrt of negative number -4
```

```epher
unknown_name
```

```text
error: unknown name: unknown_name
```

```epher
foo(1)
```

```text
error: unknown name: foo
```

最后一个示例很重要：epher 会准确告诉你它不认识哪个名称，方便你修正表达式。

## 2. 网页应用（PWA）

### 2.1 打开它

网页应用位于：

```text
https://epher.org/pwa/
```

无需安装——它在任何现代浏览器中都能运行，无论是电脑、手机还是平板。

### 2.2 你的第一个计算

1. 点击文本框（页面加载时它已经获得焦点）。
2. 输入表达式，例如 `2 + 3 * 4`。
3. 按**回车**或点击 **=** 按钮。

结果以大号文字显示在输入框下方。第 1 章的所有内容在这里都适用，包括变量、函数和脚本。

### 2.3 历史记录

每次计算都会添加到结果下方的历史列表中，你可以回看自己做过什么。历史记录在页面打开期间保留。

### 2.4 绘图

输入 `graph` 加一个表达式，然后按**回车**：

```epher
graph x ^ 2
```

epher 会从 x = −10 到 x = 10 对曲线 y = f(x) 取样，并将其绘制在输入框下方，附有说明文字显示所绘内容。你可以绘制任何表达式，包括自己的函数：

```epher
def f(x) = x ^ 3
graph f(x)
```

表达式没有值的点（例如除以零）会被跳过，在曲线中留下空隙。

### 2.5 安装与离线使用

网页应用是一个*渐进式网页应用*：访问一次后即可完全离线使用，还可以像普通应用一样安装。

- **Chrome、Edge 或 Android：** 点击地址栏中的安装图标（或浏览器菜单中的*安装应用*），然后确认。
- **iPhone / iPad（Safari）：** 点击**分享** → **添加到主屏幕**。
- **其他浏览器：** 在菜单中查找*安装*或*添加到主屏幕*。

安装后，从主屏幕或应用列表启动它——即使没有网络连接也能瞬间打开。

### 2.6 网页应用不能做什么

网页应用刻意保持简单：它计算表达式并保留会话历史。**save**、**save script** 和 **language** 命令在桌面、命令行和终端版本中都可用（第 3、4、5 章）——在网页应用中，这些命令会提示保存功能在那些版本中可用。历史记录不会在两次访问之间保存。

## 3. 桌面应用

桌面应用是同一个网页应用外面的普通窗口。第 2 章的内容全部适用；区别只在于安装和启动方式。

### 3.1 安装

从 epher 网站为你的系统下载一个安装程序：

- **Windows：** 运行 `epher-windows-x86_64.exe`。安装程序会把 `epher` 加入你的 PATH——打开一个新的 CMD 或 PowerShell 窗口，`epher "2 + 2"` 即可使用。由于构建未签名，首次启动请选择*更多信息* → *仍要运行*。
- **macOS：** 打开 `epher-macos-aarch64.dmg` 并把 epher 拖入应用程序文件夹。由于构建未签名，首次启动需要右键 → **打开**。
- **Linux（Debian/Ubuntu）：** `.deb` 包

```sh
sudo apt install ./epher-linux-x86_64.deb
```

- **Linux（Fedora/RHEL）：** `.rpm` 包

```sh
sudo dnf install ./epher-linux-x86_64.rpm
```

- **Linux（任何发行版，包括 Arch）：** AppImage——赋予执行权限并运行：

```sh
chmod +x epher-linux-x86_64.AppImage
./epher-linux-x86_64.AppImage
```

每个安装程序都包含*完整*的 epher——桌面应用、命令行（第 4 章）和终端界面（第 5 章）——全部是同一个 `epher` 命令。在 Linux 上，软件包会把 `epher` 安装到 `/usr/bin`。

### 3.2 使用

像启动其他任何应用一样启动 epher。你会看到一个与网页应用界面相同的窗口：输入表达式，按**回车**或点击 **=**，然后阅读结果。绘图在这里同样有效——`graph x ^ 2` 会在窗口中绘制（第 2.4 节）。窗口可以自由调整大小。

你也可以从终端打开它：不带参数的 `epher`（或 `epher gui`）会启动桌面应用。在 macOS 上，使用应用内的**安装 epher 命令**按钮，把 `epher` 放到终端 PATH 中。

### 3.3 存储：与 CLI 和 TUI 共用同一个存储

桌面应用与命令行和终端版本共用存储。函数、常量、脚本、历史记录和语言偏好存放在同一个地方——你电脑上的 `~/.epher`（或 `EPHER_STORE_DIR`，见第 4.6 节）——在一个版本中保存的所有内容都可以在其他版本中使用：

```text
def area(w, h) = w * h
save area
```

在桌面应用中定义 `area`，用 `save` 保存，关闭窗口——然后打开 CLI，`area(3, 4)` 直接可用。反过来也一样：打开桌面窗口时，在 CLI 或 TUI 中保存的函数和脚本已经在那里了，包括保存的脚本设置的变量。第 4 章的 `save`、`save script` 和 `language` 命令在这里的用法完全相同。

> 浏览器中的网页应用是唯一不使用这个存储的版本——每次会话相互独立（第 2.6 节）。

## 4. 命令行（CLI）

CLI 是与桌面应用同一个 `epher` 程序的文本一面。它有三种模式：单次计算、管道脚本，以及用于较长时间工作的交互式会话。

随时可以获得帮助：运行 `epher --help`（所有命令和示例），或
`epher help`（完整手册；在 Linux 安装包上就是 `man epher` 手册页）。

### 4.1 单次计算

把表达式作为参数传入：

```sh
epher "2 + 3 * 4"
```

```text
14
```

第 1 章中任何单一表达式都可以：

```sh
epher "if 3 > 2 then 10 else 20"
```

```text
10
```

以减号开头的表达式可以直接使用：

```sh
epher "-2 + 5"
```

```text
3
```

单次模式只计算一个表达式。语句——变量、函数、循环——需要交互式会话或管道脚本（第 4.2 节）。

### 4.2 管道脚本

`epher -` 从标准输入逐行读取表达式——就像脚本语言在管道中的用法：

```sh
printf "x = 3\nx * 10\n" | epher -
```

```text
= 3
= 30
```

第 1 章的所有内容都可以用，而且各行共享同一个会话：前面定义过的函数后面可用，`save` 照常写入同一个存储。出错会打印出来，脚本继续运行。

### 4.3 交互式会话（REPL）

用 `epher repl` 启动：

```sh
epher repl
```

> 不带参数的 `epher` 会打开桌面应用（第 3 章）。

epher 显示提示符并等待：

```text
epher>
```

现在逐行输入第 1 章中的任何内容。变量在行与行之间保持值：

```text
epher> x = 5
= 5
epher> x ^ 2
= 25
```

每个答案显示为 `= 结果`。输入 `quit`（或 `exit`）退出：

```text
epher> quit
```

你的历史记录会被记住：下次运行 `epher repl` 时，上一次会话的输入仍然在。

### 4.4 保存函数、常量和脚本

定义一个函数，然后保存它：

```text
epher> def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
epher> save fib
saved fib
```

`save fib` 命令把函数存到磁盘。下次启动会话时，`fib` 已经定义好了：

```text
epher> fib(10)
= 55
```

常量的保存方式相同 —— 对常量名使用 `save`：

```text
epher> const tax = 0.2
= 0.2
epher> save tax
saved tax
```

要保存整个脚本（你输入的最后一行），使用 `save script`：

```text
epher> x = 0; while x < 5 do x = x + 1; x
= 5
epher> save script count_to_five
saved script count_to_five
```

保存的脚本会在 epher 启动时自动运行，所以它们定义的一切都为你准备好了。

### 4.5 更改界面语言

界面语言取自你设备上设置的语言。要覆盖它，输入 `language` 加下列之一：`en`、`zh-CN`、`hi`、`es`、`fr`、`ar`、`de`、`pt`：

```text
epher> language fr
language set to fr
```

选择会被记住，供下次使用。注意：你*输入*的语言——表达式语言——始终相同，与界面语言无关。

### 4.6 数据存放在哪里

函数、脚本、历史记录和语言选择存放在你电脑上的一个文件夹中：

```text
~/.epher
```

删除该文件夹即可完全重新开始。要使用其他位置，请在启动 epher 前设置环境变量 `EPHER_STORE_DIR`：

```sh
EPHER_STORE_DIR=/tmp/my-epher epher repl
```

## 5. 终端界面（TUI）

TUI 是交互式会话的全屏版本，运行在终端内。它与桌面应用同属一个 `epher` 程序——用以下命令启动：

```sh
epher tui
```

### 5.1 屏幕

屏幕分为几个面板：

- **Expression**（表达式）——输入行（顶部）。
- 下方的当前**结果**。
- **History**（历史）——你输入的每一行及其答案。
- **Graph**（图表）——`graph` 命令绘制的图形（底部）。
- 提示行显示键盘快捷键。

### 5.2 按键

| 按键 | 作用 |
|---|---|
| 输入 | 添加到表达式 |
| **回车** | 计算 |
| **Esc** | 清空输入行 |
| **Ctrl+C** | 退出 |
| **q** | 退出（输入为空时） |

### 5.3 绘图

输入 `graph` 加一个表达式，然后按**回车**：

```epher
graph x ^ 2
```

epher 在 x = −10 到 x = 10 之间取样曲线，并以 ASCII 图形绘制在 Graph 面板中。图形上方的说明文字显示绘制内容：`y = x ^ 2`。

你可以绘制任何表达式，包括自己的函数——先定义一个，再绘制它：

```epher
def f(x) = x ^ 3
graph f(x)
```

表达式没有值的点（例如除以零）会被直接跳过，在图中留下空隙。

### 5.4 保存与持久化

TUI 与 CLI 共享存储：在其中一个保存的内容在另一个中同样可用。函数、脚本、历史记录和语言偏好存放在 `~/.epher`（第 4.6 节），`save`、`save script` 和 `language` 命令在这里同样有效。

## 6. 你的数据与隐私

- **已安装的 epher 程序**——桌面应用、CLI 和 TUI——把函数、脚本、历史记录和语言选择本地存放在 `~/.epher`（或 `EPHER_STORE_DIR`）。不会离开你的电脑。
- **网页应用** 不往磁盘写任何东西：历史记录只在页面打开期间有效。网页应用可以离线运行，因为页面本身由你的浏览器存储。

四个版本都在你的设备上完成全部计算——不会向任何地方发送任何内容。
