# Calc 用户指南

欢迎！Calc 是一款可编程、可脚本化的计算器。你可以用它做快速计算，也可以构建自己的函数和小程序——并且所有功能都支持六种语言。

本指南面向完全初学者。它从最简单的计算开始，逐步深入到语言的完整功能。每个示例都显示你输入的内容以及 Calc 的回应。

Calc 有四种使用方式——选择最适合你的那一种：

| 版本 | 是什么 | 何时选用 |
|---|---|---|
| **网页应用**（PWA） | 在浏览器中运行，可安装，可离线使用 | 想最快开始；无需安装 |
| **桌面应用** | 带独立窗口的常规桌面程序 | 想要一个常规应用程序 |
| **命令行**（CLI） | 终端中的文本命令；也有交互式会话 | 常驻终端、喜欢脚本 |
| **终端界面**（TUI） | 终端内的全屏程序 | 想要带图表和屏幕历史的终端应用 |

四个版本理解完全相同的语言。学会一次，随处可用。

## 1. Calc 语言

本章讲解所有 Calc 版本共享的语言。在网页应用或桌面应用中，输入表达式并按**回车**（或点击 **=** 按钮）。在 CLI 中，在 `calc>` 提示符后输入。在 TUI 中，直接输入并按**回车**。在 CLI 中你也可以输入 `calc "表达式"` 直接计算一个表达式。

### 1.1 你的第一个计算

输入：

```text
2 + 3 * 4
```

Calc 回答：

```text
14
```

乘法和数学中一样先于加法计算。这个规则称为*运算符优先级*。

### 1.2 运算顺序

完整的优先级顺序，从强到弱：

1. `^` 乘方
2. `*` 和 `/` 乘法和除法
3. `+` 和 `-` 加法和减法

用括号改变顺序：

```text
(2 + 3) * 4
```

```text
20
```

`^` 运算符计算乘方，并且从右向左结合：

```text
2 ^ 10
```

```text
1024
```

```text
2 ^ 3 ^ 2
```

```text
512
```

（`2 ^ 3 ^ 2` 表示 `2 ^ (3 ^ 2)`，即 `2 ^ 9` = 512。）

乘方可以是分数——`2 ^ 0.5` 就是 2 的平方根：

```text
2 ^ 0.5
```

```text
1.4142135623730951
```

减法和除法从左向右计算：

```text
10 - 3 - 2
```

```text
5
```

### 1.3 特殊数字 pi 和 e

两个著名的常数已经内置：

```text
pi
```

```text
3.141592653589793
```

```text
2 * pi
```

```text
6.283185307179586
```

```text
e
```

```text
2.718281828459045
```

### 1.4 比较与逻辑

你可以比较数字。结果是 `true`（真）或 `false`（假）：

| 比较 | 含义 |
|---|---|
| `a > b` | a 大于 b |
| `a < b` | a 小于 b |
| `a >= b` | a 大于或等于 b |
| `a <= b` | a 小于或等于 b |
| `a == b` | a 等于 b（注意是两个 `=`） |
| `a != b` | a 不等于 b |

```text
3 > 2
```

```text
true
```

```text
1 != 2
```

```text
true
```

用 `and`、`or` 和 `not` 组合比较：

```text
3 > 2 and 2 < 3
```

```text
true
```

```text
not 3 > 2
```

```text
false
```

### 1.5 变量

用一个 `=` 给值命名：

```text
x = 5
```

```text
5
```

Calc 会把值重复给你。从现在起，`x` 可以随处使用：

```text
x ^ 2
```

```text
25
```

你可以随时更改变量——它一直保持自己的值，直到你更改它：

```text
x = x + 1
```

```text
6
```

> 名称可以包含字母和下划线，如 `radius` 或 `my_total`。不能包含空格，也不能以数字开头。

### 1.6 用 if 做判断

`if` 在两个值之间选择：

```text
if 3 > 2 then 10 else 20
```

```text
10
```

形式永远是 `if 条件 then 为真时的值 else 为假时的值`。`else` 部分必不可少。

带变量的更有用示例：

```text
price = 100
if price > 50 then 2 else 1
```

```text
2
```

> Calc 没有文本值——`if` 的两个分支必须是数字（或比较的结果）。

### 1.7 用 while 循环

只要条件成立，`while` 就重复执行一条语句：

```text
x = 0; while x < 5 do x = x + 1; x
```

```text
5
```

把这个脚本读作：*x 从 0 开始；当 x 小于 5 时，给 x 加 1；然后显示 x。*结果是 5，因为循环执行了五次。

> **安全网：** Calc 会在 100 000 步之后停止任何循环并显示 `error: step limit exceeded`。这能保护你免受永不结束的循环的困扰。如果看到这个错误，说明你的条件可能永远不会变成假。

### 1.8 用 def 定义自己的函数

函数是带有名称和参数的计算：

```text
def f(x) = x ^ 2
```

然后使用它：

```text
f(7)
```

```text
49
```

函数可以有多个参数：

```text
def area(w, h) = w * h
area(3, 4)
```

```text
12
```

也可以定义没有参数的函数：

```text
def answer() = 42
answer()
```

```text
42
```

### 1.9 递归：调用自身的函数

最著名的例子——斐波那契数列：

```text
def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
```

```text
fib(10)
```

```text
55
```

`fib(10)` 是第 10 个斐波那契数。函数用更小的参数调用自己，直到达到 `n <= 1`。这能成立是因为 `if ... then ... else ...` 形式只计算它需要的分支。

> 函数体是一个单独的表达式——一行。需要组合多个计算时，改用 `;` 写成脚本（见下一节）。

### 1.10 脚本：一次执行多条语句

*脚本*是用 `;` 连接、依次执行的若干语句：

```text
x = 10; y = x + 5; x + y
```

```text
25
```

脚本是构建小程序的方式：设置变量、循环、显示最终结果。

### 1.11 精确结果：frac、dec 和 big

通常 Calc 像袖珍计算器一样用小数计算。有些数字用精确形式更好看。

**frac(n, d)** 生成精确分数：

```text
1 / 3
```

```text
0.3333333333333333
```

```text
frac(1, 3)
```

```text
1/3
```

分数在计算过程中保持精确：

```text
frac(1, 3) * 3
```

```text
1
```

**dec(x)** 生成精确小数。比较这两个：

```text
0.1 + 0.2
```

```text
0.30000000000000004
```

```text
dec(0.1) + dec(0.2)
```

```text
0.3
```

第一个结果是每台计算机处理小数时都会产生的微小舍入误差。`dec()` 会消除它。

**big(x)** 生成精确整数，用于超出袖珍计算器范围的数值：

```text
big(10 ^ 20)
```

```text
100000000000000000000
```

### 1.12 内置函数

Calc 有少量内置函数：

| 函数 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `sqrt(x)` | 平方根 | `sqrt(16)` | `4` |
| `min(a, b)` | 两者中较小者 | `min(3, 7)` | `3` |
| `frac(n, d)` | 精确分数 | `frac(1, 3)` | `1/3` |
| `dec(x)` | 精确小数 | `dec(0.1)` | `0.1` |
| `big(x)` | 精确整数 | `big(10 ^ 20)` | `100000000000000000000` |

它们可以像其他一切一样组合：

```text
min(sqrt(16), 5)
```

```text
4
```

### 1.13 读懂错误

出问题时，Calc 会告诉你，而不是猜测：

```text
1 / 0
```

```text
error: division by zero
```

```text
sqrt(-4)
```

```text
error: domain error: sqrt of negative number -4
```

```text
unknown_name
```

```text
error: unknown name: unknown_name
```

```text
sin(1)
```

```text
error: unknown name: sin
```

最后一个示例很重要：`sin` **不是**内置函数——只有第 1.12 节列出的那些。错误消息会准确告诉你 Calc 不认识什么，方便你修正表达式。

### 1.14 快速参考

| 功能 | 语法 | 示例 |
|---|---|---|
| 加、减、乘、除 | `+ - * /` | `7 / 2` |
| 乘方 | `^`（从右向左） | `2 ^ 10` |
| 括号 | `( )` | `(2 + 3) * 4` |
| 常数 | `pi`、`e` | `2 * pi` |
| 比较 | `> < >= <= == !=` | `3 >= 2` |
| 逻辑 | `and or not` | `a > 1 and a < 10` |
| 变量 | `name = value` | `x = 5` |
| 判断 | `if c then a else b` | `if x > 0 then 1 else -1` |
| 循环 | `while c do statement` | `while x < 5 do x = x + 1` |
| 函数 | `def name(params) = expr` | `def f(x) = x ^ 2` |
| 脚本 | 用 `;` 连接语句 | `x = 1; x + 1` |
| 精确分数 | `frac(n, d)` | `frac(1, 3)` |
| 精确小数 | `dec(x)` | `dec(0.1) + dec(0.2)` |
| 精确整数 | `big(x)` | `big(10 ^ 20)` |

## 2. 网页应用（PWA）

### 2.1 打开它

网页应用位于：

```text
https://upyesp.github.io/calc/pwa/
```

无需安装——它在任何现代浏览器中都能运行，无论是电脑、手机还是平板。

### 2.2 你的第一个计算

1. 点击文本框（页面加载时它已经获得焦点）。
2. 输入表达式，例如 `2 + 3 * 4`。
3. 按**回车**或点击 **=** 按钮。

结果以大号文字显示在输入框下方。第 1 章的所有内容在这里都适用，包括变量、函数和脚本。

### 2.3 历史记录

每次计算都会添加到结果下方的历史列表中，你可以回看自己做过什么。历史记录在页面打开期间保留。

### 2.4 安装与离线使用

网页应用是一个*渐进式网页应用*：访问一次后即可完全离线使用，还可以像普通应用一样安装。

- **Chrome、Edge 或 Android：** 点击地址栏中的安装图标（或浏览器菜单中的*安装应用*），然后确认。
- **iPhone / iPad（Safari）：** 点击**分享** → **添加到主屏幕**。
- **其他浏览器：** 在菜单中查找*安装*或*添加到主屏幕*。

安装后，从主屏幕或应用列表启动它——即使没有网络连接也能瞬间打开。

### 2.5 网页应用不能做什么

网页应用刻意保持简单：它计算表达式并保留会话历史。**save**、**save script** 和 **language** 命令在桌面、命令行和终端版本中都可用（第 3、4、5 章）——在网页应用中，这些命令会提示保存功能在那些版本中可用。历史记录不会在两次访问之间保存。

## 3. 桌面应用

桌面应用是同一个网页应用外面的普通窗口。第 2 章的内容全部适用；区别只在于安装和启动方式。

### 3.1 安装

从 Calc 网站为你的系统下载桌面应用：

- **Linux（Debian/Ubuntu）：** `.deb` 包

```text
sudo apt install ./calc-desktop-linux-x86_64.deb
```

- **Linux（Fedora/RHEL）：** `.rpm` 包

```text
sudo dnf install ./calc-desktop-linux-x86_64.rpm
```

- **Linux（任何发行版）：** AppImage——赋予执行权限并运行：

```text
chmod +x calc-desktop-linux-x86_64.AppImage
./calc-desktop-linux-x86_64.AppImage
```

- **macOS：** 打开 `.dmg` 并把 Calc 拖入应用程序文件夹。由于构建未签名，首次启动需要右键 → **打开**。
- **Windows：** 运行安装程序。由于构建未签名，首次启动请选择*更多信息* → *仍要运行*。

### 3.2 使用

像启动其他任何应用一样启动 Calc。你会看到一个与网页应用界面相同的窗口：输入表达式，按**回车**或点击 **=**，然后阅读结果。窗口可以自由调整大小。

### 3.3 存储：与 CLI 和 TUI 共用同一个存储

桌面应用与命令行和终端版本共用存储。函数、脚本、历史记录和语言偏好存放在同一个地方——你电脑上的 `~/.calc`（或 `CALC_STORE_DIR`，见第 4.5 节）——在一个版本中保存的所有内容都可以在其他版本中使用：

```text
def area(w, h) = w * h
save area
```

在桌面应用中定义 `area`，用 `save` 保存，关闭窗口——然后打开 CLI，`area(3, 4)` 直接可用。反过来也一样：打开桌面窗口时，在 CLI 或 TUI 中保存的函数和脚本已经在那里了，包括保存的脚本设置的变量。第 4 章的 `save`、`save script` 和 `language` 命令在这里的用法完全相同。

> 浏览器中的网页应用是唯一不使用这个存储的版本——每次会话相互独立（第 2.5 节）。

## 4. 命令行（CLI）

CLI 是 Calc 的文本版本。它有两种模式：用于快速结果的单次模式，和用于较长时间工作的交互式会话。

### 4.1 单次计算

把表达式作为参数传入：

```text
calc "2 + 3 * 4"
```

```text
14
```

第 1 章中任何单一表达式都可以：

```text
calc "if 3 > 2 then 10 else 20"
```

```text
10
```

如果表达式以减号开头，用 `--` 告诉 CLI 表达式从哪里开始：

```text
calc -- "-2 + 5"
```

```text
3
```

单次模式只计算一个表达式。语句——变量、函数、循环——需要交互式会话。

### 4.2 交互式会话（REPL）

不带参数启动会话：

```text
calc
```

Calc 显示提示符并等待：

```text
calc>
```

现在逐行输入第 1 章中的任何内容。变量在行与行之间保持值：

```text
calc> x = 5
= 5
calc> x ^ 2
= 25
```

每个答案显示为 `= 结果`。输入 `quit`（或 `exit`）退出：

```text
calc> quit
```

你的历史记录会被记住：下次启动 `calc` 时，上一次会话的输入仍然在。

### 4.3 保存函数和脚本

定义一个函数，然后保存它：

```text
calc> def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
calc> save fib
saved fib
```

`save fib` 命令把函数存到磁盘。下次启动 `calc` 时，`fib` 已经定义好了：

```text
calc> fib(10)
= 55
```

要保存整个脚本（你输入的最后一行），使用 `save script`：

```text
calc> x = 0; while x < 5 do x = x + 1; x
= 5
calc> save script count_to_five
saved script count_to_five
```

保存的脚本会在 Calc 启动时自动运行，所以它们定义的一切都为你准备好了。

### 4.4 更改界面语言

界面语言取自你设备上设置的语言。要覆盖它，输入 `language` 加下列之一：`en`、`zh-CN`、`hi`、`es`、`fr`、`ar`：

```text
calc> language fr
language set to fr
```

选择会被记住，供下次使用。注意：你*输入*的语言——表达式语言——始终相同，与界面语言无关。

### 4.5 数据存放在哪里

函数、脚本、历史记录和语言选择存放在你电脑上的一个文件夹中：

```text
~/.calc
```

删除该文件夹即可完全重新开始。要使用其他位置，请在启动 Calc 前设置环境变量 `CALC_STORE_DIR`：

```text
CALC_STORE_DIR=/tmp/my-calc calc
```

## 5. 终端界面（TUI）

TUI 是交互式会话的全屏版本，运行在终端内。用以下命令启动：

```text
calc-tui
```

### 5.1 屏幕

屏幕分为几个面板：

- **Expression**（表达式）——输入行（顶部）。
- 下方的当前**结果**。
- **History**（历史）——你输入的每一行及其答案。
- **Graph**（图表）——`graph` 命令绘制的图形（底部）。
- 提示行显示键盘快捷键。

### 5.2 按键

| 按键 | 作用 |
|---|---|
| 输入 | 添加到表达式 |
| **回车** | 计算 |
| **Esc** | 清空输入行 |
| **Ctrl+C** | 退出 |
| **q** | 退出（输入为空时） |

### 5.3 绘图

输入 `graph` 加一个表达式，然后按**回车**：

```text
graph x ^ 2
```

Calc 在 x = −10 到 x = 10 之间取样曲线，并以 ASCII 图形绘制在 Graph 面板中。图形上方的说明文字显示绘制内容：`y = x ^ 2`。

你可以绘制任何表达式，包括自己的函数——先定义一个，再绘制它：

```text
def f(x) = x ^ 3
graph f(x)
```

表达式没有值的点（例如除以零）会被直接跳过，在图中留下空隙。

### 5.4 保存与持久化

TUI 与 CLI 共享存储：在其中一个保存的内容在另一个中同样可用。函数、脚本、历史记录和语言偏好存放在 `~/.calc`（第 4.5 节），`save`、`save script` 和 `language` 命令在这里同样有效。

## 6. 你的数据与隐私

- **CLI 和 TUI** 把函数、脚本、历史记录和语言选择本地存放在 `~/.calc`（或 `CALC_STORE_DIR`）。不会离开你的电脑。
- **网页应用** 不往磁盘写任何东西：历史记录只在页面打开期间有效。网页应用可以离线运行，因为页面本身由你的浏览器存储。
- **桌面应用** 将函数、脚本、历史记录和语言选择保存在本地的 `~/.calc`（或 `CALC_STORE_DIR`）中，与 CLI 和 TUI 使用同一个存储。不会向你的电脑之外发送任何内容。

四个版本都在你的设备上完成全部计算——不会向任何地方发送任何内容。
